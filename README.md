# codealpha_calculator

Summer internship task: basic calculator.

## Calculator

A basic calculator built with HTML, CSS, and JavaScript.

## Features

- Arithmetic operations: `+`, `-`, `×`, `÷`
- Button-based UI + display screen
- Clear screen
- Real-time preview result while typing
- Keyboard support (digits, `.`, `+ - * /`, `Enter` for equals, `Esc` to clear)

## Run

Open `index.html` in a browser.
